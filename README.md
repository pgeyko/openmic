# OpenMic

Открытая беспроводная замена DroidCam / WoMic для Linux (целевой дистрибутив — ALT Linux):
превращает Android-смартфон в качественный беспроводной микрофон с минимальной задержкой.

Звук со смартфона транслируется по Wi-Fi или USB-кабелю и определяется в системе как нативный виртуальный источник PipeWire (`Audio/Source`), доступный во всех браузерах (Chrome, Chromium, Firefox), Zoom, Telegram, OBS и Discord.

---

## Архитектура и особенности

- **Минимальная задержка**: Передача сырого PCM (48 кГц, 16 бит, моно) по прямому TCP-соединению. Отсутствие перекодирования экономит процессор ПК и заряд батареи телефона.
- **Поддержка двух каналов связи**:
  - **Wi-Fi**: Быстрое сопряжение по QR-коду (или авто-настройки).
  - **USB (ADB)**: Работа по кабелю через `adb forward` с задержкой < 20 мс и зарядкой смартфона во время звонков.
- **Двустороннее управление**:
  - Настройка громкости (0–200%) и Mute на ПК.
  - Управление аппаратным шумоподавлением телефона прямо из интерфейса на ПК.
- **Android-клиент**:
  - Фоновый сервис (`FOREGROUND_SERVICE_MICROPHONE`) с `PARTIAL_WAKE_LOCK`: стабильная работа при заблокированном экране.
  - Быстрое переключение через плитку в шторке уведомлений (Quick Settings Tile).
  - Опциональный самоконтроль (мониторинг звука в наушники).
  - Живой визуализатор звука (Waveform).
- **Десктопный клиент (GTK4 + Libadwaita)**:
  - Единая точка входа: автоматически запускает и гасит фоновый демон.
  - Живая волна звука с цветовой индикацией уровня и клиппинга.
  - Автоматическое отслеживание смены IP-адреса ПК при переключении сетей.

## Быстрый старт на Linux (ALT Linux)

### 1. Системные зависимости
Для сборки десктопной части требуются библиотеки GTK4 и PipeWire:
```bash
sudo apt-get update
sudo apt-get install rust rust-cargo libgtk4-devel libadwaita-devel pipewire-utils
```

### 2. Установка приложения
В корне проекта выполните установочный скрипт (не требует прав root):
```bash
./install.sh
```
После этого в меню приложений появится **OpenMic**, а в терминале станут доступны команды:
- `openmic-gtk` — графический интерфейс управления.
- `openmic` — консольная утилита для скриптов и терминала (`openmic status`, `openmic doctor`, `openmic gain 150`, `openmic mute`).

## Сборка Android приложения

Для изолированной сборки APK без захламления системы в проекте настроен локальный скрипт окружения:
```bash
. ./env.sh
cd android
./gradlew assembleDebug
```
Готовый файл APK будет находиться в `android/app/build/outputs/apk/debug/app-debug.apk`.
Установка на подключенный смартфон:
```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## Использование

1. Запустите **OpenMic** на компьютере (через системное меню или команду `openmic-gtk`).
2. Откройте приложение на смартфоне.
3. Нажмите **«Сканировать QR-код»** и наведите камеру на QR-код в окне на ПК (или выберите режим **USB**, если телефон подключен кабелем).
4. Нажмите **«Начать эфир»**.
5. В Zoom, Telegram или браузере выберите микрофон **OpenMic**.
