## Возможности

- **Нативный источник PipeWire**: В системе создаётся виртуальный микрофон `OpenMic` (`Audio/Source`), который нативно поддерживается всеми приложениями: **Telegram, Zoom, Discord, OBS, Google Chrome, Chromium, Firefox**.
- **Минимальная задержка (< 30 мс)**: Трансляция сырого несжатого PCM-аудио (48 кГц, 16 бит, моно) по прямому TCP-соединению без задержек кодеков и без нагрузки на CPU.
- **Два равноправных режима связи**:
  - **Wi-Fi**: Быстрое сопряжение через сканирование QR-кода прямо с экрана монитора.
  - **USB (кабель)**: Стабильный проводной канал через `adb reverse` с нулевой зависимостью от Wi-Fi роутера и одновременной зарядкой смартфона.
- **Двустороннее управление (S→C)**:
  - Управление программным усилением (0–200%) и глушением звука на ПК.
  - Удалённое переключение аппаратного шумоподавления на телефоне прямо из интерфейса на ПК.
- **Стабильная работа в фоне**: Foreground-сервис на Android с блокировкой `PARTIAL_WAKE_LOCK` — звук не обрывается при заблокированном экране и в кармане.
- **Быстрый доступ**: Плитка в шторке быстрых настроек Android (Quick Settings Tile).
- **Современный GUI (GTK4 + Libadwaita)**: Живой визуализатор уровня звука (Waveform), динамическое определение IP при смене сети, единая точка входа (GUI сам управляет фоновым демоном).

## Архитектура

```
   Android-смартфон                          Linux (ALT Linux, Ubuntu, Fedora)
┌─────────────────────────┐               ┌─────────────────────────────────────┐
│ AudioRecord (48kHz/16b) │               │ openmicd (фоновый демон)            │
│ NoiseSuppressor (HAL)   │   TCP:59100   │  ├ FIFO / Unix-сокет                │
│ Low-latency AudioTrack  │ ────────────► │  ├ pipewire (module-pipe-source)    │
│ NetClient (Auto-reconn) │ ◄──────────── │  ├ S->C Control (управление NS)     │
│ Quick Settings Tile     │  (NS Control) │  └ D-Bus / Socket API               │
└─────────────────────────┘               └──────────────────┬──────────────────┘
                                                             │
                                                  ┌──────────┴──────────┐
                                                  │ openmic-gtk (GUI)   │
                                                  │ openmic (CLI)       │
                                                  └─────────────────────┘
```

## Установка на Linux (ALT Linux и др.)

### 1. Системные зависимости
Для работы PipeWire и сборки GUI:
```bash
# ALT Linux (p10 / p11 / Sisyphus)
sudo apt-get update
sudo apt-get install rust rust-cargo libgtk4-devel libadwaita-devel pipewire-utils

# Ubuntu / Debian
# sudo apt install cargo libgtk-4-dev libadwaita-1-dev pipewire-bin
```

### 2. Установка
В корне репозитория запустите скрипт установки (не требует root):
```bash
git clone https://github.com/username/openmic.git
cd openmic
./install.sh
```

Скрипт автоматически:
- Соберет релизные бинарники (`openmic-gtk`, `openmicd`, `openmic`).
- Установит их в `~/.local/bin/`.
- Зарегистрирует векторные и растровые иконки всех размеров в системе.
- Установит ярлык меню `openmic.desktop`.

После этого приложение появится в меню вашей среды (раздел «Аудио и видео»), а также станет доступна команда `openmic-gtk`.

## Использование

1. Запустите **OpenMic** на компьютере (через меню приложений или `openmic-gtk`). Демон запустится автоматически.
2. Откройте **OpenMic** на смартфоне.
3. Нажмите **«Сканировать QR-код»** и наведите камеру на QR-код в окне на ПК (или выберите режим **USB**, если подключен кабель).
4. Нажмите **«Начать эфир»**.
5. В любимом приложении для связи (Telegram, Zoom, OBS, Discord) выберите устройство ввода **OpenMic**.

## Клиент для Android

Каркас приложения расположен в каталоге `android/`:
- **Язык**: Kotlin, Android SDK 34 (minSdk 26).
- **Сборка**:
  ```bash
  . ./env.sh
  cd android
  ./gradlew assembleDebug
  ```
  Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
- **Быстрая установка через ADB**:
  ```bash
  just apk-install
  ```

## Консольный интерфейс (CLI)

Для автоматизации и использования в терминале доступна утилита `openmic`:
```bash
openmic doctor          # Диагностика PipeWire, прав и токена
openmic status          # Текущий статус сопряжения и параметры сети
openmic gain 150        # Установить усиление на 150%
openmic mute            # Заглушить микрофон
openmic unmute          # Включить микрофон
openmic ns on           # Включить шумодав на телефоне
openmic tonesend        # Тестовый прогон 440 Гц тона через конвейер
```
